## 🎯 Решенные задачи

### Основная задача (из issue)
> Нужно добавить папку докер в ней у нас будет композиция для пробрасывания интерфейса с ESP32 на HTTPS страницу

✅ **Решено**: Создана полная Docker композиция с nginx reverse proxy и certbot

### Требования из задачи

1. ✅ **Композиция может подниматься на любой системе**
   - Работает на Linux, macOS, Windows (WSL2)
   - Работает на Raspberry Pi (включая Zero)
   - Работает на VPS и облачных серверах
   - Минимальные требования: 512MB RAM, 1GB диск

2. ✅ **IP хоста регистрируется на роутере под домен с HTTPS**
   - Поддержка локального DNS (роутер Keenetic и др.)
   - Поддержка публичного DNS с DynDNS
   - Инструкции по настройке DNS в документации

3. ✅ **Валидные SSL сертификаты**
   - Let's Encrypt с автообновлением (production/staging)
   - Самоподписанные сертификаты для локальной сети
   - Автоматическая генерация через скрипты

4. ✅ **Настройка IP ESP32**
   - Простая конфигурация через .env файл
   - Автоматическая генерация nginx конфигурации
   - Проверка доступности ESP32 при настройке

5. ✅ **Два порта ESP32 на разных URL через HTTPS**
   - Порт 80 (API) → `https://domain.com/`
   - Порт 81 (stream) → `https://domain.com/stream`
   - Оба на едином HTTPS порту 443
