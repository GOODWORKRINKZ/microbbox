🤖 МикРоББокс - Дифференциальное Управление

                
Демонстрация работы джойстиков в дифференциальном режиме

                
                

                    
✨ Особенности Дифференциального Режима

                    

                        

                            
◄═══► Левый Слот

                            
Горизонтальный слайдер

                            
Управление поворотом робота (влево/вправо)

                            
Круг движется только по горизонтали

                        

                        

                            
▲ Правый Слот ▼

                            
Вертикальный слайдер

                            
Управление скоростью (вперед/назад)

                            
Круг движется только по вертикали

                        

                        

                            
⚙️ Принцип Работы

                            
Дифференциальная передача

                            
Левый мотор = Скорость + Поворот

                            
Правый мотор = Скорость - Поворот

📐 Формулы Расчета Скорости Моторов

                    

                        Входные данные:

                        • speed = rightJoystick.y × speedSensitivity

                        • turn = leftJoystick.x × turnSensitivity
                    

                    

                        Расчет скорости моторов:

                        • leftMotorSpeed = speed + turn

                        • rightMotorSpeed = speed - turn
                    

                    

                        Примеры:

                        📍 Движение вперед: speed=80, turn=0 → Left=80, Right=80

                        📍 Поворот направо: speed=80, turn=40 → Left=120, Right=40

                        📍 Поворот налево: speed=80, turn=-40 → Left=40, Right=120

                        📍 Разворот на месте: speed=0, turn=60 → Left=60, Right=-60
                    

                


                

                    
🎮 Как Использовать

                    

                        

                            
1️⃣ Движение Вперед/Назад

                            
Используйте ПРАВЫЙ СЛОТ

                            
▲ Сдвиньте круг вверх = вперед

                            
▼ Сдвиньте круг вниз = назад

                        

                        

                            
2️⃣ Повороты

                            
Используйте ЛЕВЫЙ СЛОТ

                            
◄ Сдвиньте круг влево = поворот налево

                            
► Сдвиньте круг вправо = поворот направо

                        

                        

                            
3️⃣ Комбинированное Управление

                            
Используйте ОБА СЛОТА

                            
Для плавных поворотов на ходу

                            
Комбинируйте скорость и поворот одновременно
